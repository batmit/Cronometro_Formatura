# Formatura em Medicina · 2026

Página responsiva com três contagens regressivas, atualizadas a cada segundo:

- Churrasco de formatura: 16/12/2026 às 18h.
- Colação de grau: 17/12/2026 às 19h.
- Festa de formatura: 19/12/2026 às 16h.

Todos os eventos usam o horário de Brasília (UTC−3), independentemente do fuso do visitante. Ao chegar à data, o contador fica em zero e exibe uma mensagem de celebração.

A seção de memórias exibe as 14 fotos de `assets/`, uma por vez, com transição horizontal a cada 8 segundos. Use as setas para avançar ou voltar e o botão abaixo para pausar ou retomar. As teclas de seta também funcionam quando a galeria está em foco. Mantenha a pasta `assets` junto ao `index.html` para abrir a versão local.

Abra `index.html` no navegador. Não é necessário instalar dependências. Os botões “Salvar na agenda” baixam arquivos `.ics` para importar no calendário. As fontes do Google são opcionais; sem internet, a página usa as fontes locais.

Para alterar as datas, atualize o array `events` e os textos e atributos `datetime` dos cartões em `index.html`.
